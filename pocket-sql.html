About Pocket SQL

Pocket SQL is an interactive SQL practice terminal powered by SQL.js that runs entirely in your browser. Whether you're a student learning SQL for the first time or a developer brushing up on database skills, Pocket SQL provides a convenient, portable way to practice SQL commands without any installation.

Built with modern web technologies, Pocket SQL brings the power of SQLite to your fingertips. Create multiple databases, execute complex queries, and manage relationships - all offline and completely private.
