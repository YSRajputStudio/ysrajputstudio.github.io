# YSRajput Studio

The official website for **YSRajput Studio** — an independent digital studio building apps and platforms that solve real, everyday problems.

## About

YSRajput Studio builds digital products that work for real people. From hyperlocal job marketplaces to short-video platforms, every project starts with a genuine problem — not a trend.

A one-person studio. Small team, clear focus, and a long-term view on every product put into the world.
